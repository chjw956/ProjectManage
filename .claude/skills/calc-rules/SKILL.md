# 계산 규칙

계산은 모두 `*Calculator` 클래스(순수 함수, DB 접근 없음)에 둔다.
"오늘"은 주입한 `Clock`에서 가져온다. **테스트를 먼저 작성하고 구현한다.**

## 1. 진척률

- Task 진척률 = 입력한 진행률 (0~100)
- 공정 진척률 = 하위 Task 진행률을 **계획 기간(일수)으로 가중 평균**
- 사업 진척률 = 공정 진척률을 공정 계획 기간으로 가중 평균
- 계획 기간이 없는 Task는 가중치 1일로 계산한다.
- 반올림은 마지막에 한 번만 (정수 %)

## 2. Task 지연 판정

- 지연: 상태 ≠ 완료 이고 오늘 > 계획 종료일
- 또는 오늘 기준 기대 진행률(경과일 ÷ 계획 기간) − 실제 진행률 ≥ 30%p

## 3. 사업 상태 신호 (설계서 6.2)

| 상태 | 조건 (하나라도 해당) |
| --- | --- |
| 위험 | 마일스톤 14일 초과 지연 / 해결 기한을 넘긴 상급 이슈 / 정부사업 의무 기한 초과 미제출 |
| 주의 | 마일스톤 14일 이내 지연 / 열린 상급 이슈 1건 이상 / 14일 이상 미갱신 / 예산 지연 1건 이상 |
| 정상 | 위 조건 없음 |

- 위험 조건을 먼저 검사한다. 응답에는 상태와 함께 **판정 사유 목록**을 넣는다.
- "미갱신"은 해당 사업의 마지막 event 생성일 기준이다.

## 4. 예산 집행 시기 분류 (설계서 4.11)

- 기준일 = 기준 이벤트 예정일. 미정이면 시기 = "미분류"
- 비교일 = 실집행일, 없으면 계획일
- 비교일 < 기준일 → "설립 전·선투자", 비교일 ≥ 기준일 → "설립 후"

## 5. 예산 집계

- **입력 불완전 항목은 합계에서 제외**하고 건수를 따로 반환한다: 계획금액 미정, 집행 주체 미지정, 입력 확인 필요
- 계획 총액 = Σ 계획금액 / 집행 총액 = Σ 집행금액 / 집행률 = 집행 총액 ÷ 계획 총액 (계획 총액 0이면 null)
- 지연 건수 = 실집행일 없음 이고 오늘 > 계획일
- 월별 소계: 계획은 **계획일의 월**, 집행은 **실집행일의 월**에 집계. 데이터가 없는 중간 달도 행을 만든다 (값 null)
- 월별 누계: 첫 달부터 차례로 더한 값. 잔여 = 누계 계획 − 누계 집행 (음수 허용)
- 누적 집행률 = 누계 집행 ÷ 누계 계획
- 기준 이벤트가 있는 달은 `isBaseEventMonth = true`로 표시

## 필수 테스트 케이스

- [ ] 하위 Task가 없는 공정의 진척률
- [ ] 계획 기간이 서로 다른 Task 가중 평균
- [ ] 오늘 = 계획 종료일 (지연 아님), 다음 날 (지연)
- [ ] 상태 판정: 위험·주의 조건이 동시에 있으면 위험
- [ ] 기준일 미정 → 미분류, 비교일 = 기준일 → 설립 후
- [ ] 계획금액 미정 항목이 합계에서 빠지고 건수에 잡힘
- [ ] 계획보다 많이 집행 → 잔여 음수
- [ ] 계획만 있고 집행이 없는 달, 둘 다 없는 중간 달
- [ ] 계획 총액 0 → 집행률 null (0으로 나누기 없음)
